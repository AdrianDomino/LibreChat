# LibreChat Technology Stack

## Technologies Used

### Frontend Technologies
- **React**: 18.x with TypeScript for component-based UI
- **Vite**: Build tool for fast development and optimized production builds
- **Tailwind CSS**: Utility-first CSS framework for styling
- **React Query**: Data fetching and caching
- **React Hook Form**: Form handling and validation
- **Socket.io Client**: Real-time communication
- **React Router**: Client-side routing
- **Zustand**: Lightweight state management

### Backend Technologies
- **Node.js**: 18.x+ runtime environment
- **Express.js**: Web framework for REST APIs
- **MongoDB**: Primary database for conversation storage
- **Redis**: Caching and session management
- **Socket.io**: Real-time bidirectional communication
- **Mongoose**: MongoDB object modeling
- **JWT**: Authentication tokens
- **bcrypt**: Password hashing
- **Multer**: File upload handling
- **Sharp**: Image processing

### AI Provider Integrations
- **OpenAI API**: GPT models and DALL-E
- **Google AI**: Gemini and PaLM models
- **Anthropic**: Claude models
- **Azure OpenAI**: Enterprise OpenAI service
- **AWS Bedrock**: Amazon's AI service
- **Hugging Face**: Open-source models
- **Local AI**: Self-hosted models via Ollama, LM Studio

### File Processing
- **PDF.js**: PDF document processing
- **Tesseract.js**: OCR for image text extraction
- **FFmpeg**: Audio/video processing
- **Sharp**: Image manipulation and optimization
- **Mammoth**: DOCX to HTML conversion

### Development Tools
- **TypeScript**: Type safety and modern JavaScript features
- **ESLint**: Code linting and style enforcement
- **Prettier**: Code formatting
- **Jest**: Unit testing framework
- **Cypress**: End-to-end testing
- **Docker**: Containerization
- **GitHub Actions**: CI/CD pipeline
