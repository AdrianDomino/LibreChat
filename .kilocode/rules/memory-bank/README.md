# LibreChat Memory Bank

This directory contains the persistent memory and context tracking system for the LibreChat project. It maintains project state, decisions, patterns, and progress across sessions.

## Structure

- `core/` - Core project documentation and context
- `sessions/` - Active session tracking and state
- `tasks/` - Progress and task management
- `patterns/` - Code patterns and conventions
- `decisions/` - Decision tracking and rationale
- `usage/` - Usage instructions and guides

## Usage

This memory bank is automatically maintained by the Kilo Code system to provide context-aware assistance across sessions. Files are updated as the project evolves.

## Files

- `README.md` - This overview file
- `project-context.md` - Core project information
- `active-session.md` - Current session state
- `progress.md` - Task and progress tracking
- `patterns.md` - Code patterns and conventions
- `decisions.md` - Decision log
- `usage.md` - Usage instructions
